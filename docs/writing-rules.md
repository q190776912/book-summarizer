## 单元化写作流程（write-source 步骤 4–6，2026-08-31 起）

> 写源阶段不再基于「整章草稿」写作，而是**以拆分出的单元为底稿，在步骤 5
> 逐个改好**。步骤 6 只是纯脚本拼接，**不再需要 agent 参与**。

- **拆分**（步骤 4，纯脚本）：`split_draft_units.py` 把内容化分章契约拆成
  按写作顺序的单元目录 `units/ch{N}/`——**每个编号项（定义/定理/例等，含其内部
  证明）一个独立 md 文件**，另有章标题 / 节标题 / 描述散文单元。每单元首行是
  `<!-- book-summarizer DRAFT unit: … -->` 标记。
- **逐个改好**（步骤 5 核心，agent）：打开每个单元文件，按本文件各规则改好该
  单元内容（公式重写 / Tier 压缩 / 格式落地）——**全部写作要求在此落实**，
  并把首行 `DRAFT` 改为 `DONE`。**禁止跳过任何单元。**
- **🔴 强制门控**（步骤 5 末尾，脚本）：`gate_units.py` 核对每个单元「存在 +
  首行 DONE + **单元级质量校验通过**」——🔴 2026-09-01 起判断标准是**「写对」
  而非「重写」**：`check_unit_quality.py` 对每个 item/desc 单元校验——全部引用
  verify 已有检测函数，不重复造轮子：
  - **公式闭合**：`check_katex.check_display_math_closure`（同 verify F 层）
  - **裸数学/箭头**：`katex_heuristics.find_bare_math_errors` / `find_raw_arrow_errors`
    （同 verify F 层）
  - **证明过长**：`verbose_gates.check_verbose_proofs`（同 verify P 层）
  - **结构标签**：`struct_labels.TOP_LEVEL_HEADER_RE`（同 verify H 层）
  - **example blockquote**：`format_verify.check_example_blockquote_lines`（同 verify G 层）
  - **OCR 残留**：verify 不覆盖的 OCR 公式模式（`\ensuremath` `\pmb` 等）由薄封装补充
  ——拦模型瞎改就标 DONE。只有全部单元都改对（每个 item 都不漏）才 exit 0，否则列出
  未达标清单。未过 gate 严禁进入步骤 6 拼接。
- **拼接**（步骤 6，纯脚本无 agent）：`merge_units.py` 按 manifest 顺序合并全部
  单元为最终 `ChapterN_*.md` / `第N章_*.md`，并按本文件 [V-F](#v-f-格式与块引用f-层母文档)
  规则重建条目级 `---` 分隔线（节标题前 / item↔item / item↔desc 之间加 `---`；
  章/节标题之下第一元素、连续 desc 不加；堆叠 `---` 自动合并）。
  🔴 **merge 自带强制门控**：拼接前先跑 `gate_units`，任一单元未改好（首行非
  DONE / 质量未达标 / 缺失）即直接报错拒绝拼接——即使跳过 `gate_units` 单独跑
  merge 也会被拦截。
- 单元内「结构骨架」不可重排、不可自创层级；公式是 OCR 原样，**严禁照抄**，
  须按本文档重写校正。

## OCR 噪声处理原则

OCR on scanned mathematical textbooks produces **noisy text and severely corrupted LaTeX formulas**. This is expected and not a bug. The correct approach:

**OCR text → understand → correct → write, NOT OCR text → copy → paste.**

- **正文 (body text)**: Usually readable (70-95%). Use directly after correcting obvious encoding artifacts.
- **公式 (formulas)**: Usually severely garbled (e.g. `\pmb{\mathscr{R}}` for $\mathcal{R}$). **NEVER copy these directly.** Read the formula's semantic intent from the broken LaTeX + surrounding context, then rewrite it correctly from your knowledge of the subject.
- **定理/定义编号 (theorem/definition numbers)**: Usually legible. Use directly.
- **节标题 (section headings)**: Usually legible. Use directly.

**When in doubt** about a specific formula or concept, fall back to your knowledge of the textbook's subject matter.

## 核心原则

The summary must mirror the original book's content faithfully:

- **允许修正 OCR 噪声**：编号模糊时还原（`定? 2.?-1` → `定义2.8-1`），内容模糊时基于上下文 + 学科知识复原原意。
- **允许适度精简**：精简的是表述不是内容——压缩冗余铺陈，但不得省略任何编号项，也**不得省略描述性内容（动机/直观/导语等）中的公式与概念**（带编号公式的保留要求见 [V-C](#v-c-内容保真extract--公式保真)；"精简"的量化边界见下方 [保真分级](#保真分级tier-123) 与 [V-C 反过度精简](#v-c-内容保真extract--公式保真)）。
- **不允许无中生有**：书本没讲的概念不要编进去，书本没出现的编号不要硬加。
- **不允许统一风格**：不得为美观把原书的 `定义2.1.1` 改成 `定义2-1-1`。
- **不允许创造编号**：无编号章节不强行编号。
- **双源铁律（结构 ≠ 内容）**：正文**必须回归 `page_*.json` 原文**，禁止把结构契约的 `name` 当作正文来源、禁止脱离契约自创结构或重排顺序；契约只告诉你"有什么标题 / 在哪几页"，原文才告诉你"写什么内容"（详见 [V-C](#v-c-内容保真extract--公式保真)）。

## 保真分级（Tier 1/2/3）

> 🔴 本节是**内容取舍尺度的唯一权威**。`verify/verbose_gates/script/verbose_gates.py` 的层注释、`verify/script/report.py` 的提示文案、`flows/write-source/write-source.md` 的保真底线，凡出现 "Tier N" 一律引用本节，**不得另立解释或口头发挥**。

总结允许压缩**表述**，不允许删除**内容**。三档分级只决定"语言写得多紧凑"，**不决定"这段留不留"**：

| 档位 | 覆盖对象 | 压缩尺度 | 硬底线（不可越过） |
|------|----------|----------|--------------------|
| **Tier 1** 高保真 | 定义 / 定理 / 引理 / 命题 / 推论 / 公理的**陈述**，**例题题面**，**注记（Remark / Aside）** | 只修 OCR 噪声，尽量原样 | 逐句保留，不省略从句、条件与限定语 |
| **Tier 2** 描述性内容 | 节/子节导言、动机、直观、物理解释、建模铺垫、算法说明、结果讨论、章末小结 | **只压修辞性铺陈**：重复措辞、客套话、文献罗列、同义反复 | 🔴 **三不删**：① 不删**数学对象**（变量 / 符号 / 空间 / 映射 / 算符 / 参数，含其定义域、陪域与语义）；② 不删**任何公式**（带编号的、无编号展示式、承载定义或关键关系的行内式）；③ 不删**概念名**（术语及其首次出现的解释）。**不得整段删除**源段落——每个源自然段至少在总结中留下一句承载其信息的句子 |
| **Tier 3** 推导过程 | 证明 / 求解过程 / 例题解答 | 压成 `1. 2. 3. …` 核心步骤 | 每步一句话，**跳步不得跳过关键变量替换或关键等式**；步骤数按实际需要，不限 |

**Tier 2 正反例（最常见的失分点）**：

- ❌ **元叙述替代内容**：`This section presents the definition of the Koopman operator.` 是原书的导语套话，**不是内容**。总结要写的是"该节实际讲了什么"，而不是"该节说它要讲什么"。
- ❌ **删光建模铺垫**：源写 "Consider a discrete-time system defined by the nonlinear transformation $S:X\to X$, where $X$ is a finite-dimensional metric space … one can focus on an output function $f:X\to\mathbb{C}$, also called observable" → 总结若只剩 `**Definition 1.1**` 的公式，就把状态空间 $X$、映射 $S$、可观测量 $f$、轨道 $\{S^k(x)\}$ 全丢了。**一个都不能少**。
- ❌ **只留结论不留条件**：源给了假设（光滑性 / 有界性 / 正则性 / 紧性），总结只抄结论。
- ❌ **删掉结果的解释**：定理后源文解释"这意味着什么 / 何时取等 / 直观如何"，属 Tier 2 实质内容，须保留一句。
- ✅ **允许**：三句同义铺陈合成一句；删掉 "It is well known that" / "In this chapter we will" 类套话；把 `[12, 34, 56]` 的文献罗列压缩为"（综述见文献）"；把重复出现的同一记号只在其**首次出现处**解释一次。

## 编号规范（编号还原）

Numbering in OCR output is often corrupted. Two-step approach:

1. **Decipher the original**: Look at broken OCR + surrounding context to infer what the book actually shows.
2. **Restore the original**: Write the number as the book intended it.

Common patterns (after correction):

- **Dash**: `N.S-N` (e.g. `定义1.1-1`)
- **Dot**: `N.S.N` (e.g. `定义2.1.1`)
- **Single-level**: `1`, `I`, `a` (e.g. `定理1`, `例a`)
- **No number**: Just `**定理（名称）**：` if the book really omits it

**Allowed**: Fix OCR noise to restore the intended number (`定?` → `定义`, `2.?-4` → `2.8-4`).
**Not allowed**: Inventing numbers or labels that don't appear in the book, or rebracketing for consistency（编号形态以原书为准，见 [V-I](#v-i-编号项收录b-层--硬性要求-3-5)）。

## 双语规则与输出语种

### 输出语种（按你手上的书的语种决定）

"原书"指你正在总结的那本书（译本也算），不追查原始出版语言：

| 你手上的书的语种 | 输出 |
|---------|------|
| 中文书 | 仅中文总结（`第N章_章名.md`，N 用阿拉伯数字如`第1章`） |
| 英文书 | 两份：**`ChapterN_*.md` 纯英文源版（全文件禁止任何中文字符）** + **`第N章_*.md` 中文派生版（中文为主、保留英文术语标注）** |
| 其他语种（德/法/日/俄…） | 原语种 + 中英双份（共三份） |

### 英文标注原则（仅中文版需要）

中文版必须在每个章文件内首次出现重要概念时标注英文，**格式为 `中文 (English)`**。包括：

- 节标题：`## §N.1 节名 (English Section Title)`（原书小节带序标时）；原书小节**无**序标时写 `## § 节名 (English Section Title)`（数字留空，仅保留 `§`，详见下方「小节序标必须尊重原书」规则）。
- 定义/定理标签：`**定义N.S-N（名称 (English name))**`。
- 裸编号项：`**N.S-N 中文名 (English name)**`。
- 正文关键术语：该章内首次出现时括号标注。不同章之间独立。

**英文来源规则**：

- 若**原书本身是英文**或原书在概念旁已给出英文术语，则标注的英文**基于原书原文**，不自行另译。
- 若原书无对应英文，则按你的理解给出标准英文翻译。

> 🔴 **铁律 — 英文源版 `ChapterN_*.md` 必须 100% 英文，禁止任何中文字符**：
> - 标签**只写英文**，如 `**Definition 1.1 (Joint Distribution Function)**`，**绝不**写成 `**联合分布函数 (Joint Distribution Function)**` 或 `**定义1.1**`。
> - 正文、节标题、图注 `alt="..."` 一律英文；**全角中文标点 `：` `（` `）` 也必须换成半角 `:` `(` `)`**。
> - 中文**只许**出现在 `第N章_*.md`（中文派生版）。在该文件里首次出现概念时用 `中文 (English)` 标注。
> - 违反此条 → 英文版既不像英文、又与中文版重复，整章作废重做。英文版内容与中文版**结构镜像**，但**语言纯英文**。

## 编号项格式模板

**带标签项**（定义/定理/命题/推论/引理）——中文版：

```
**定义1.1-1（名称 (English name)）**：定义内容。
**定理2.6-2（名称 (English name)）**：陈述内容。

> **证明思路**：1. 第一步。 2. 第二步。 … N. 最后一步。

> **证明梗概（别名）**：`**证明梗概**` 是 `**证明思路**` 的等价别名，两者适用完全相同的格式规则（均须 `>` 块引用包裹、多步骤须 `1. 2. … N.` 编号）。
```

**无标签裸编号项**——中文版：

```
**2.8-4 范数 (Norm)**：描述内容。
```

**明确标"例"的项**——中文版（例子用 `>` 包裹，例内证明与例子同一层 `>`，不用 `> >` 嵌套；陈述与证明必须在同一连续 blockquote 中，中间不得有空行或裸 `$$`）：

```
> **例1.1-2（名称 (English name)）**：简要描述。
> **证明思路**：1. 第一步。 2. 第二步。 … N. 最后步骤。
```

> 编号格式跟原书走。OCR 模糊时允许还原编号，但**不得无中生有**，也不得为统一风格而篡改原书的分隔符。
> 如果某节内容在书中是原理性描述（无编号也无标签），直接用带 `**` 的段落叙述，不强制编号。
> 正文中首次出现的关键术语也要标注英文。
> 例块连续性、条间分隔等块引用/分隔线细则见 [V-F](#v-f-格式与块引用f-层母文档)；习题收录规则见 [V-I](#v-i-编号项收录b-层--硬性要求-3-5)。

## 提取流程（从 JSON 提取编号项）

写任何一章之前，先对该章页码范围内的 **JSON 页面文件** 直接做分析（不要依赖 chN_raw.txt，JSON 保留原始 OCR 文本块且不被模拟拼接破坏）。

> **核心策略**：不在图像预处理层面提升 OCR 质量。而是通过**脚本层三级兜底**——(1) 主正则 `N.S-N`、(2) 2-group fallback `(\d)(\d)...` 捡回 OCR 连写编号、(3) `--manual` 人工补漏应对完全不可读的碎片。

1. **确定页码范围**：从 `chapter_map.json` 获取该章的 start/end 页码。
2. **遍历该范围内所有 JSON page**，按页码顺序逐页读取。**JSON 中 `text` 数组的排列顺序不一定等于页面阅读顺序**；必须用每条 text 的 `poly` 坐标对同页内的 text 排序，然后全局按页顺序 + Y 坐标确定全部 text 的阅读流。
   **正则匹配编号**：每条 text 正文用 `(\d+)\s*[\.\-\·\，\s]\s*(\d+)\s*[\-\.\·\，\s]\s*(\d+)` 检测 `N.S-i` 模式（脚本中 `num_re`）。注意 OCR 可能把短横打成点，此时按上下文判断。
3. **放宽标点限制**：序号分隔符可能是 `.` `-` `·`（中文间隔号 U+00B7）`，` 甚至空格。统一还原为原书格式。
4. **区分"标签项"与"引用"**：每个匹配的编号需要判断是**原创条目**还是**交叉引用**。
   - **标签检测**（三级优先级）：① 当前 text block（编号前后 60+40 字符含标签词）；② 整节标签（该节内未显式标注的编号继承节标题标签）；③ 邻接 text block（最后手段）。
   - **引用检测**：若编号前 25 个字符内有"见""由""根据""参考""参见""Cf."等词，则标记为引用，不收录。
5. **检查边界头丢失**：对每节，如果检测到的第一个编号 > 1，怀疑更小编号被页边界吞掉，回 JSON 上下页确认。
6. **检查内部密集性**：对每节编号进行跨度分析，空缺编号回 JSON 对应页确认是否存在。
7. **人工补漏**（针对 OCR 完全吃掉编号的条目）：在 `manual_overrides_ch{N}.json` 中写好漏项的 `key` / `label` / `page` / `text`，运行 `flows/write-source/structure/script/extract_items` 配合 `--manual` 合并输出。**尾部缺漏必须迭代检查**，直到 WARN 消失。
8. 将确认后的条目录入清单，确认每条都有对应标签后，再动笔写正文。
9. 写完后对照清单检查一遍，确认无遗漏。

## verify 收敛区（唯一规则源）

> 🔴 本节是**所有**会被 `verify` 校验的「写作期规则」的**唯一载体**。每条规则按校验层分组（V-C / V-I / V-S / V-P / V-F / V-K / V-E / V-M）。正文其余位置与 `verify/*.md` 均不重复这些规则；子文档只写机器判定与修复实现。写源阶段读完本节即覆盖 verify 全部写作约束。

### V-C 内容保真（EXTRACT / 公式保真）

- **🔴 绝不照抄 OCR 公式**：OCR 出的 LaTeX 几乎总是错的。读懂其语义意图后，**凭学科知识重写正确 LaTeX**，严禁把 `formulas[].latex` 直接粘贴进 `.md`。（依据：`page_*.json` 的 `formulas[].latex` 是"原书公式内容真相"，但需重写而非照抄。）
  - ❌ 照抄：`\| x _ { \mathfrak { n } } - x _ { \mathfrak { m } } \| ^ { 2 } = \int _ { 0 } ^ { 1 } [ x _ { \mathfrak { n } } ( t ) - x _ { \mathfrak { m } } ( t ) ] ^ { 2 } d t`
  - ✅ 重写：`\|x_n - x_m\|^2 = \int_0^1 [x_n(t) - x_m(t)]^2 dt`
- **语义保真（不得偷换）**：OCR 编码噪声（如 `\pmb{\mathscr{R}}` → `\mathcal{R}`）可修正，但**数学语义**（算符 / 运算元 / 关系 / 集合符号 / 常数）必须与原书一致。
  - ❌ 错（语义改变）：PDF 是 `= \emptyset`，总结写 `= 0`。
  - ✅ 对：PDF `= \emptyset` → 总结 `= \emptyset`；PDF `{\cal L}_{A_c}` → 总结 `L_{A^c}`（同义、记号归一允许）。
- **双源回归**：正文内容必须来自 `page_*.json` 原文（经 `data/page_json/page_json.py` 的 `page_text()` / `text_blocks`）；分章契约（`book_structure/ch{N}.json`）只定骨架（标题 + 页码区间），**不是正文来源**。
- **🔴 反过度精简（覆盖下限）**：本条是 [保真分级](#保真分级tier-123) Tier 2「三不删」的**可核对落地口径**。凡源书**引入**的数学内容，总结必须逐一落地：
  - **变量 / 符号**：源中出现的每个变量、参数、空间、映射、算符，其**记号 + 类型或定义域/陪域 + 语义**必须在首次出现处写清（如 `$S:X\to X$`、可观测量 `$f:X\to\mathbb{C}$`）；后文沿用同一记号，不得默默换字母。
  - **公式**：带编号公式按上文 1:1 保留；**无编号展示式**与**承载定义/关键关系的行内式**（如 `$\dot x=F(x)$`、`$U^{t}f=f\circ S^{t}$`）同样必须保留，不得以"只是推导过程"为名整段略去。
  - **概念**：源中给出名称的概念（isochron / isostable / observable / Fokker-Planck …）须保留**名称 + 一句解释**，不得退化成"某种方法"。
  - **段落映射**：源每个自然段在总结中至少有一句对应，**禁止整段删除描述段**；章首摘要（Abstract）须并入 `## §N.1 Introduction`（或该章首节）而非丢弃。
  - **机器辅助**：`tools/coverage_gate.py` 逐章给出**压缩比 / 术语覆盖率 / 变量覆盖率**，任一项低于阈值即判过度精简（阈值与判据见该工具 `--help`）。
- **🔴 所有带编号公式必须 1:1 保留（含描述性散文 / 推导式）**：书源以 `(N.M)` / `(N)` / `(N.M.K)` / `(N.M-N)` 等带编号呈现的公式，无论出现在定理陈述还是描述性推导中，都必须出现在总结里并挂 `\tag{<原书编号>}`；**不得以"精简"为由省略**（精简只压缩铺陈、不省编号公式）。唯一合法省略路径：在 `verify_config.json` 的 `formula.ignore` **显式登记**该编号。未登记的遗漏会被 Q 层判 **MISSING → FAIL（阻断）**。

### V-I 编号项收录（B 层 / 硬性要求 3-5）

- **🔴 例必录**：每个 `例` / `Example` 都必须写入，不得只留 0–3 个；保留原书编号（如 `例 3a`）。
- **🔴 标签项必录**：带标签的条目（定义/定理/命题/推论/引理）与无标签裸编号段（如 `2.8-4 Norm`）**全部必录**；每条独立写成粗体标签条目，禁止合并多条。
  - **🔴 禁止"裸项"伪类别标签**：`**N.S-N 裸项（…）**：` 是擅自发明的写法，必须清除。类别词位置 **1:1 照搬原书印刷标题**（编号在前如 `4·1-1定义` 就编号在前；类别在前如 `定理 4.3-3` 就类别在前），不强行统一。
  - 书中条目有明确类别 → 按真实类别写（`定理`/`定义`/`引理`/`推论`/`命题`/`例`）；本就无类别的裸编号段 → 照原书裸编号写（`**2.8-4 Norm**：…`），不套"裸项"、不硬塞类别。
  - **🔴 禁止章末 `## 图片索引` 附录**：图片只做内联嵌入（见 [V-E](#v-e-图片归属e-层)），`figure_index.md` 仅是便于粘贴的辅助文件，不并入章总结。
- **🔴 不编造编号（硬性要求 5）**：每个编号标签必须源自书源。不得给无编号叙事段强加编号；不得重复编号、不得串号。书无编号的概念写成加粗叙事（`**换位子 (Commutator)**：…`），不套编号标签。
- **习题（练习）收录规则**（判定标准 = 有无专门习题小标题归拢）：
  - **有专门习题小标题的集中习题块**（`### 练习` / `## §1.11 习题` / `**习题**` / `Exercises` / `Problems` 下罗列的编号题）→ **一律省略**，直接跳过、不写注记；整节都是习题的节同理省略。
  - **无标题、穿插出现的习题**（散落正文条目间，或节末无标题归拢）→ **保留**，原位写出题目（OCR 噪声须重写正确 LaTeX），可附提示。
  - ⚠️ 校验口径：集中习题块节点标 `consolidated:true` 并在 verify 真相集排除（既不写也不校验）；被保留的穿插练习**既写也纳入编号项校验**（真实条目，漏写/跳号应被发现）。早期"练习一律不校验"的表述作废。

### V-S 结构完整性（D / B / O 层）

- **D 层 — 节的连续性（§ 结构不得断 / 缺）**：
  - 所有源有节（`## §N.M...`，含子节）必须按分章契约（`book_structure/ch{N}.json`）逐节写出，不得整节漏写、不得重排。
  - 内部断裂（写了 §1.1、§1.3，源有 §1.2）→ 整章 FAIL；首节缺失同理；尾节落在 md 最后一节之后 → 整章 FAIL。
  - 无序号标书（`section_types` 含 `0`，如 Silverman）：小节只写 `## § <描述性标题>`（数字留空），闸门按"位置/数量"比对（只查契约要求的每节是否都在 md，不报 md 多出的小节）。
  - 缺节只能补写（回源确认确缺则补整节 + 修契约），**绝不为 PASS 把缺节塞进 ignore**。
- **B 层 — 编号项完整性 + 顺序**：
  - 同 `type`（按书 `ordinal` 分组）下，编号序列从首项起、中间不得断号；断号即真漏项（strict 下 BLOCKING），尾部比源少仅 WARN。
  - **🔴 顺序必须单调不减（始终 BLOCKING，不随 strict 降级）**：同节前缀内按阅读顺序去重后的编号须单调递增；大号在前小号在后 = 确定性错误，写时即按原书阅读顺序排。
  - **🔴 ignore 审计铁律（防隐藏真实缺项）**：凡被验证章节存在"编号 ignore"条目，收尾跑 `audit_ignore.py`——**序列洞型 ignore 必须带显式证据标记**（`VERIFIED-SPARSE` / `源书真实跳号` / `已核实跳号` / `sparse numbering` 之一）才判 `ACCEPTED`；无证据标记的序列洞 ignore 一律判 `SUSPECT` → 校验不得 PASS。回源确认真漏才补写并在 `manual_overrides_ch{N}.json` 登记；仅确认是书本身稀疏/ OCR 噪声才进 `ignore`。
  - OCR 误报过滤：提取侧报"缺 X"但 X 已在 `.md` 正确写出 → verify 自动抑制该 BLOCKING，但要确认 `.md` 确实写了。
- **O 层 — 编号子项连续性**（`(1)(2)(3)` / `(a)(b)(c)` / `(i)(ii)(iii)`）：块内带括号子编号序列必须连续（起始 >1 或 min–max 间缺号 → 视为真实遗漏，BLOCKING）；仅当块内序号项 ≥3 才检测（避免把交叉引用误判为序列）。O 管"子项是否连续"，与 [V-F](#v-f-格式与块引用f-层母文档) 的 J 层（块内分隔线）互补。

### V-P 反照抄与自造结构闸门（P 层，不可 `--fix`）

> P 层 7 道闸门中，p_exer_block / p_missing_sec / p_extra_item / p_bare_item 已分别并入 [V-I](#v-i-编号项收录b-层--硬性要求-3-5) / [V-S](#v-s-结构完整性d--b--o-层) D.B / [V-S](#v-s-结构完整性d--b--o-层) B / [V-I](#v-i-编号项收录b-层--硬性要求-3-5)，此处只列 P 层独有的写作约束：

1. **剔除 OCR 噪声（p_noise）**：页眉 / 页脚 / 版权行（如 "Foundations of Algebraic Geometry"、"Published by …"、"© 2024 …"、孤立页码行）不得混进正文。取 `page_text()` 后人工剔除此噪声。
2. **🔴 顶层纯散文不得整段照抄（p_verbose）**：顶层纯散文段（不含 `**` 标签条目/例/练习/注记忠实内容、且**不含公式**）段数 ≥6 → FAIL。忠实描述须"改写表述"而非整段照抄（Tier 1/2/3 分级），但**承载数学（`$...$`/`$$`/含公式）的顶层段落豁免**（视为 Tier 2 须保留公式与概念）。含公式段落不算 padding。
   - 🔴 **判定的是"照抄"，不是"写得长"**（2026-08-28 用户裁决：**优先保证可读性，不以纯字数论处**）。纯长度只是代理，会与 Tier 2「保留全部变量/公式/概念 + 基本描述」直接冲突——忠实但已改写的密集数学散文天然偏长，被纯长度闸门误杀后只能靠删内容过关。故单段违规须满足二者之一：
     - **改写不足**：长度 > 450 字 **且** 与源书 `page_*.json` 的 8-gram **字面重合率 ≥ 60%**（逐字照搬原文）→ 须改写表述（保留全部变量/公式/概念）；
     - **可读性硬顶**：长度 > 1200 字的墙式散文，无论重合率一律违规 → 须分段。
   - 换言之：**改写得好的长段不违规**；只有"照抄"和"墙式不分段"才违规。
3. **🔴 内容不得过短（p_undercover，与第 2 条反向的闸门）**：第 2 条只罚"太长/照抄"，本条罚"太短/漏内容"——防止把 Tier 2 描述段整段删光导致"看不懂"。判据由 `tools/coverage_gate.py` 给出：章级**压缩比**（md 正文词数 ÷ 源正文词数，源侧已剔除页眉页脚与参考文献）与逐节**术语覆盖率**（源侧专有名词/技术词在 md 中的出现比例）、**变量覆盖率**（源侧 LaTeX 符号在 md 中的出现比例）。低于阈值即 FAIL，须回源补写，不得靠调阈值或 ignore 蒙混。阈值以 `coverage_gate.py --help` 的当前默认值为准。按 Tier 2 落笔即自然满足。
4. **🔴 证明/解答块不得过长未分条（p_proof_verbose）**：单个 `> **证明/解答**` 块 >700 字且未分条枚举、且此类块 ≥2 → FAIL。已用 `1. 2. 3. …` 分条枚举的证明（步数不限）豁免；例（Example）题面与注记（Remark/Aside）按 Tier 1 忠实保留、不参与 verbose 判定。写证明时凡多步即分条编号。

### V-F 格式与块引用（F 层母文档）

> 本小节是格式约定的 **SSOT**（verify 的 F 层 `format_verify.md` 明确以本节为唯一权威）。格式机器判定（层号 G/H/I/J/K/L/M/N、修复器、字节契约键）见 `verify/format_verify/format_verify.md`，写源不必记层号——按本小节落笔即 100% 通过 F 层。

- **🔴 粗体行内标签，禁 `###` 条目标题**：定义/定理/命题/推论/引理/公理/注记写成 `**标签**：`；例用块引用 `> **例…**：`。`###` 只用于 `##` 下的真子节分隔，且必须带 `§` 前缀。
  - 原书小节带序标 → `## §3.2 节名`；无序标（如 Silverman）→ `## § <描述性标题>`（数字留空，不编造）；gm 体例书条目小节用 `### N. Title`（不加粗、不加冒号、照原书标题，下方不得紧接 `---`）。
  - **🔴 结构性标签（定义/定理/引理/推论/命题/断言/公理）必须顶层，禁止进块引用**：写成 `> **引理X**` 会被吞进上一个 `> **证明**` 块引用，破坏结构。只有**证明**与**例/Example** 才用 `>` 包裹。
- **🔴 每个 item 上下需有 `---` 分隔线（按边界自适应）**：
  > "item" = 编号项（定义/定理/命题/推论/引理/公理/`**裸编号段**`）与例（`> **例**`）。每个 item 的**上边界与下边界**都应有 `---` 分隔线，按下列边界规则自适应：
  - **item 与 item 之间**：上一 item 内容块结束后另起一行写 `---`、再空一行写下一 item（含 `**定义**`/`**定理**` 后接 `> **例**`、或 `> **例**` 后接顶层 `**定义**`/`**定理**` 的情形）。
  - **item 上方是章/节/子节标题（`#` / `##` / `### `）时不加 `---`**：标题紧邻下一行不能是 `---`（"标题 → 引子 → `---`"合法）。即 item 紧跟在标题之下时，其上方分隔线省略。
  - **item 上方或下方是描述性散文（不含 `**` 标签条目 / 例 / 证明块的顶层叙述段落）时必须加 `---`**：item 与描述之间用 `---` 断开（上方描述 → `---` → item，或 item → `---` → 下方描述）。
  - **若该边界已存在 `---`，不再重复添加**（避免双分隔线）。
  - **定理/定义与它的证明（`> **证明**`）、`**证明思路**` / `**注记**` 等 item 内部附属块之间禁止 `---`**——证明与注记是条目的内部附属块，不是独立条目，不能用 `---` 与所属 item 分隔。
- **标题紧邻下不加 `---`**：节标题紧邻下一行不能是 `---`（"标题 → 引子 → `---`"合法）。
- **列表后空行**：列表（顶层 `1.` / `1)` / `(1)` / `- * +`，或 4 空格缩进伪列表）的最后一个列表项之后若接**非下级的新块**（`> **证明**`/`**例**` 引用块、`$$` 公式、顶层 `**标签**`、图），两者之间**必须有空行**——否则新块被渲染器吸进列表项、右偏移到列表层级（如定理陈述列表后直接接证明块）。下级缩进内容与后续列表项不需空行。
- **节标题上方必须空行**：任何 ATX 标题（`#`…`######`，如 `## §12.5 …`）的上一行必须是空行——标题若紧接有序列表项（`10. …`）或普通段落行，会被渲染器吸进上方块，标题及其下整节缩进、失去左对齐。文件首行除外；`--fix` 可自动补（🔴 全层 `--fix` 默认禁用，须 `--fix --fix-force` + PREFLIGHT；F 层 `heading_blank_above`）。
- **`---` 上下必须空行**：每个 `---` 分隔行上、下都须有空行（防被误解析为 setext 标题下划线）。
- **`$$...$$` 内不得有 `>`**：`$$` 开闭之间的每行只能是公式内容；`>` 泄漏进 `$$` 会被 KaTeX 当数学字符。块引用内的 `$$` 写成 `> $$` / 公式行顶层 / `> $$`，不要 `> > $$`。
- **块引用内空 `>` 行 ≤ 1**：`> **证明**` / `> **例**` 内连续空 `>` 行（恰好 `>` 或 `> `）最多 1 个，多余是抽取噪声。
- **例与证明分两行（同一连续块引用内）**：`> **例**` 行只含例子描述，其证明必须另起 `> **证明梗概**：` 行，不得同行（同行导致块内换行困难、校验难定位）。
- **连续例必须在顶层用 `---` 分隔**：即使多个例共享同一 `>` 块（续行连接），每个 `> **例**` 之间也须用顶层 `---` + 空行断开，每个例独占独立块引用（否则 I 层漏检、阅读看不出边界）。
- **例块连续性**：例的陈述与证明必须在同一连续 blockquote 中，禁止裸空行（无 `>` 的纯空行）或裸 `$$`（无 `>` 的展示公式）打断；需留白用 `>`（空引用行），需公式用 `> $$`。
- **半包例子可自动修复**：若例子头带了 `>` 但正文（方程组/文字）留在顶层裸奔（即"只有第一行有 `>`"），属半包缺陷。`tools/wrap_examples_bq.py` 与 `verify --fix` 的 G 层 fixer 现均能识别并整段收进 `>` 块（幂等；🔴 全层 `--fix` 默认禁用，须 `--fix --fix-force` + PREFLIGHT）；但 G 层 DETECTOR（`check_g_quote_continuity`）会先判 FAIL，需跑 `--fix`（强制启用）或该工具修复。`wrap_examples_bq` 旧版只匹配顶层 `**例/Example**` 头、会跳过已带 `>` 的头导致永远修不动，此盲区已在两处脚本修正。
- **证明块下方缺 `---` 可自动修复（中英文 Proof 均识别）**：`> **证明**` / `> **Proof sketch**` 等证明块（正文已整体在 `>` 内）结束后，若紧接描述性散文而无 `---` 分隔（视觉上"证明像吞了后续描述"），`verify --fix` 的 G 层 fixer（`fix_blockquote_continuity._ensure_proof_separator`）会自动在证明块下方插 `---`（幂等，重跑不重复插入；🔴 全层 `--fix` 默认禁用，须 `--fix --fix-force` + PREFLIGHT）。证明检测已双语化：`bq_core.PROOF_RE`/`PROF_LINE_RE`/`NESTED_BQ_RE`、`struct_labels.G_PF_RE`、`fix_blockquote_continuity._SAME_LINE_EX_PROOF_RE` 现均覆盖 中文 证明/证明思路/证明梗概/证明概要 与 英文 Proof/Proof sketch/Proof outline/Proof of …；块扩展遇到新的 `>` item 头（例/Proof/定理等）即停止，避免把后续例块吞入证明。

### V-K KaTeX 规则与公式序标（F 层 C 子层 + Q 层）

> 本小节是公式渲染与公式序标的 **SSOT**。各条由 verify 的 KaTeX 校验（`verify/format_verify/script/check_katex.py`，C 层）强制；具体 pass 编号与 `--fix` 修复见 `verify/format_verify/format_verify.md`，写源不必逐条记 pass 号。公式序标结构校验由 Q 层（`verify/formula_tag/`）负责，内容对错由人核对 `formula_audit.md`。

**KaTeX 基础格式**

0. **先保证 UTF-8（硬性要求 #1）**：文件须为干净 UTF-8；写后 spot-read 前几行确认中文可读；中文路径下跑 `check_katex.py` 须直传 `pdfextract` Python，勿经 `cmd /c`。
1. **`$$` 前必须有空行**：否则 KaTeX 忽略该显示公式。
2. **块引用内 `> $$`**：公式在块引用内时，`> **证明思路**：` 文字与 `> $$` 之间插一个空 `>` 行。
3. **避免 `> > $$` 嵌套**：`$$` 只用最外层 `>`，嵌套块内的公式拍平。
4. **避免 `\bigl(\sup\{` / `\bigl(\inf\{`**：改用 `\sup\{...\}` 或 `\bigl(\sup_{...}`。
5. **避免 `\left.\frac{}{}\right|_{}`**：改用 `\dfrac{df}{dx}\bigr|_{x=x_0}`。
6. **避免 `\[` / `\]`**：显示公式一律 `$$...$$`。
7. **禁止用 ` ``` ` 代码围栏包裹公式 / 交换图表**：公式（含交换图表）必须用真 KaTeX——普通公式 `$$ ... $$`，交换图表 `$$ \begin{CD} ... \end{CD} $$`（AMScd 语法）。AMScd 速查：`@>>>` 右、`@<<<` 左、`@VVV` 下、`@AAA` 上；右箭头上方 `@>f>>`、下箭头左侧 `@VfVV`；`@|` 竖直恒等、`@=` 水平恒等、`@.` 空格子。
8. **禁止原始 Unicode 数学箭头 / 关系符**（`↪ ↠ ↦ → ⇒ ⇔ ≅`）：必须与公式字体一致地改写成 KaTeX（映射：`↪`→`\hookrightarrow`、`↠`→`\twoheadrightarrow`、`↦`/`↣`→`\mapsto`、`→`→`\to`、`⇒`→`\implies`/`\Rightarrow`、`⇔`→`\iff`、`≅`→`\cong`）。口诀：正文出现这些字形且不在 `$...$`/`$$...$$` 内即错误。
9. **禁止裸 LaTeX 命令出现在数学模式外**：`\mathrm{op}`、`\operatorname{Hom}`、`\mathbb Z`、`\varphi:A\to B` 等若没包在 `$...$`/`$$...$$` 内，Markdown 会当普通文本显示。口诀：一行里出现 `\xxx` 就必须处于 `$...$`/`$$...$$`/代码围栏内。给裸公式补 `$` 时**绝不能把行首结构前缀**（`>` / `-` / `(a)` / `1.`）**一起包进公式**（如 `> - \mu_* 单` 修成 `$> - \mu_*$ 单` 是错的，应 `> - $\mu_*$ 单`）。
10. **公式编号必须用 `\tag{<原书编号>}` 写在 `$$` 块内部**（闭合 `$$` 之前）**：编号形态逐字照搬原书（`(7)`→`\tag{7}`、`(1.17)`→`\tag{1.17}`、`(11.1-1)`→`\tag{11.1-1}`）；禁止把编号写成公式块外的独立文字行（如 `（式 (1.17)）`）。编号后紧跟解释文字 → 编号移入 `\tag{}`、解释文字作公式后正常段落。
11. **`$` 必须成对闭合（尤其中文标点）**：`$formula，` 是最常见隐蔽 bug——中文逗号/句号前缺闭合 `$` 会让数学模式吞掉下一行 `$$` 首字符。诊断：奇数个 `$` 的行且其后紧跟 `$$`。
12. **`$$` 不得包裹非数学内容**：`$$` 内须为纯数学 LaTeX，不能含中文文本、`##` 标题或 `$...$` 内联数学。
13. **断裂命令修复**：自动修复脚本有时破坏命令间距，产生不可识别控制序列（如 `\in t`→`\int`、`\in fty`→`\infty`、`\in f`→`\inf`、`\qquadn`→`\qquad n`、`\quadc`→`\quad c`、`\widetildeP`→`\widetilde P`、`\fracx3`→`\frac{x}{3}`）。
14. **交换图（CD）语法**：箭头方向标记首尾必须匹配（`@VlabelV` 首 V 尾 V、`@AlabelA` 首 A 尾 A）；`@A\int A` 解析失败，改用 `@V\int VV`；`\begin{CD}`/`\end{CD}` 必须被 `$$` 包裹。
15. **集合花括号必须转义**：`$A_n={x : ...}$` 错，须 `\{`/`\}`。
16. **`$$` 块内禁止空行**：空行可能被部分渲染器视为显示块中断。
17. **🔴 禁止「字符型公式」——所有数学必须走 KaTeX**：任何数学内容都须用 `$...$`/`$$...$$` 渲染，绝不允许裸字符留在正文。
    - **(A) 裸 Unicode 数学字形**（强制）：σ √ ∑ ∞ ≤ ≥ ≠ ≈ ≡ × ÷ ± ∓ ∂ ∇ ∏ ∪ ∩ ∈ ∉ ⊂ ⊆ ∀ ∃ ∅ ℝ ℕ ℤ ℂ，以及希腊字母 α–ω / Γ–Ω。这些在总结里几乎不作散文出现，一律视为错误（如 `σ²t`→`$\sigma^{2}t$`、`x∈ℝ`→`$x\in\mathbb{R}$`）。上标数字 ²³ 暂不强制（物理单位误报），但数学里 `n²` 仍应 `$n^{2}$`。
    - **(B) ASCII 数学写成纯文本**（强制）：概率/期望/方差算符 `Pr{`/`Pr(`/`E[`/`Var(`/`Cov(`，单字母函数调用 `X(t)`/`p_k(n)`/`f(x+y)`，变量+下标数字 `x0`/`t1`/`y2`。必须包进 `$...$`（如 `设 $p_{k}(n)=\Pr\{\text{…}\}$`、`$X(t)$ is continuous`、`初始位置 $x_{0}$`、`$\mathbb{E}[X]$`）。
    - 本规则与 #8（Unicode 箭头/关系字形）、#9（裸 LaTeX 命令）共同构成「数学必须渲染」三道防线。
18. **🔴 超长显示公式行 → `\tag` 重叠（折行规则；F 层 `long_formula_rows` 每章自动 WARN）**：带 `\tag` 的显示公式，若单行内容**可视长度**超过阈值（默认 100 可视字符 ≈ 渲染宽 50–60 em；长行会在右端顶到编号 → 视觉重叠），须**改公式排版、不改编号**：
    - **判定**：`verify_chapter.py` 跑每章即报 `F-LAYER FORMAT · 长公式行 (WARN, non-blocking)`（含行号 / `\tag{}` / 可视长度）；批量预检可用 `tools/scan_long_formulas.py <book_dir> [阈值]`。
    - **折行位置**：只在**顶层**（花括号深度 0、括号深度 0、不在 `\left…\right` 内）的二元运算符 `=` / `+` / `-` 处断行；绝不切进分数、矩阵、指数、`\text{…}` 内部；断行不改任何数学语义与 `\tag{原编号}`。
    - **写法**：长行包进 `\begin{aligned}…\end{aligned}`——首行保留左侧对齐，续行用 `& \qquad <运算符> …`（示例：`\frac{\mathrm{d}\nu}{\mathrm{d}t} &= \frac{1}{T K_{eff} K_m}\{\cdots \right. \\ &\qquad \left. - P_0 - P_1 - \cdots \},`）。
    - **不可折环境**（`matrix`/`array`/`cases`/交换图 `\begin{CD}` 等整块宽度天然超界）：不做硬折行，靠查看器横向滚动兜底（CSS `.katex-display { overflow-x: auto; }`）。
    - **批量折行工具**：`tools/wrap_long_formulas.py <book_dir> [阈值]`（先出 dry-run 计划供审，确认后再落盘）。

**公式序标（编号 1:1 真实性，Q 层校验）**

> 🔴 **总原则（高于一切）**：公式编号形态以原书为准，本技能不规定任何固定编号格式——书上怎么写就怎么写。`\tag{}` 仅强制"编号须进 `$$` 块、随公式同行显示"这一呈现方式，括号内 `<原书编号>`（层级/分隔符/是否含字母）须逐字照搬原书。

- **无编号不加 `\tag`**：原书公式本身无编号，总结也不加 `\tag`（机器只核对带 `\tag` 的公式）。
- **有编号须 1:1 跟书**：`\tag{X}` 编号必须来自书源真实编号集合 S（每章 `page_*.json` 的 `text[]` 抽出），不得：
  - **编造（FABRICATED）**：`\tag` 编号不在 S 中；
  - **错位/跨章（INCONSISTENT）**：同章内 `\tag` 重复，或编号首分量 ≠ 当前章号；
  - **遗漏（MISSING）**：S 中属本章的编号在总结无对应 `\tag`（默认仅 WARN，永不阻断；属合理省略时加入 `formula.ignore` 跳过比对）。
- **OCR 还原边界**：允许因 OCR 模糊基于上下文还原编号（`（1l.1）`→`(1.1.1)`），只要能在 S 对应到真实编号；禁止无中生有（S 中没有的编号宁可退化为无编号公式也不许编造）；禁止为统一风格篡改分隔符（`norm()` 把 `.\-·,` 任一归一为 `.` 再比对，但总结 `\tag` 应与书源书写一致）。
- **🔴 字母/罗马开头的编号（`(A.3)` / `(I.2)`）目前会使 Q 层 FAIL（blocking）**：`norm()` 与 `build_formula_patterns()` 当前只识别"数字开头"编号，字母/罗马开头正则匹配不到 → 集合 S 空 → 字母编号被静默忽略造成假绿，故只要书源抽到任意字母/罗马开头编号，`_detect_letter_led_formulas` 即触发、**Q 层对该章判 FAIL（blocking）**——须先补「可选首段 `[A-Za-z]{1,4}[.\-·,]` 前缀 + 罗马数字」支持（代码留 TODO(letter-led)）才能放行，不得用 WARN 假绿。作者在此之前仍须按书原样写 `\tag{A.3}`。

### V-E 图片归属（E 层）

> 本小节是图片嵌入的**写作规范 SSOT**（figure 层 E 的具体判定/分档以 `verify/figure_completeness/figure_completeness.md` 为机器权威，本书不重复）。图片流水线跑过后，`_extract/figure_index.json` 列出所有图的位置、图号、裁剪文件 `figure/chNN_figX.X.X.png`；写章总结须按本小节决定每张图取舍与位置。

- **每张图只嵌入一次，且必须紧贴「使用它的条目」**：
  | 图来自的部位 | 该图在 `.md` 中的归属 |
  |--------------|----------------------|
  | caption 明确指向条目编号（含 `定理N.S-N`/`例N.S-N`/`定义…`/`引理…`/`推论…`） | 嵌入该条目陈述段后、证明块引用之前/之中 |
  | caption 是独立图号 `图N`、无明确条目编号，但与某例/定义语义配套 | 嵌入对应例或定义陈述段后 |
  | 仅作某条证明插图（caption 形如 `图M 定理X.X-X 的证明(a)`） | 嵌入该证明 `> **证明**：` 块引用**内**、与证明文字并列 |
  | 与任何条目均无关联（纯装饰、章首导览、章末示意） | **不嵌入** |

- **🔴 图必须归属正确层级（重中之重）**：caption 含 `证明`/`例N` 的图，归属块是 `> **证明…**`/`> **例…**`，嵌入须写成 `> ![…](…)` 且位置落在引用块内部（可块首/中/尾，但必须带 `>` 前缀，绝不能是顶层行）；陈述级配图（图注无 `证明`/`例`）放在条目陈述段后**顶层**，与 `> **证明**` 块并列、互不嵌套。引用块内**不得出现裸空行**（留白用 `> `），否则预览器把块切断。

- **嵌入语法**：图片用 **HTML `<img>`**（不用 markdown `![…](…)`），百分比宽度按原书比例缩放，**所有图片（含单张）统一包裹在 flex 容器内**：
  ```
  <div style="display:flex; gap:6px; flex-wrap:wrap; justify-content:center">
    <img src="figure/chNN_figX.X.X.png" alt="图N 简注" width="X%" height="auto">
  </div>
  ```
  - `width="X%"` = `(bbox_crop_w + 16) / 1653 × 100`（bbox 来自 `figure_index.json`，+16 为 8px 裁剪余量；1653px = A4 页面 200 DPI 宽）。
  - 路径相对书根；🔴 2026-09-01 起 `figure/` 目录与总结 md 同级（在书根下），链接即 `figure/chNN_...png`（非 `_extract/figure/...`）。
  - 图块单独成行，放在条目后或证明内；**图块后接 `---`** 才算条目正式收尾。
  - 多图并排放在同一 flex 容器（总宽 ≤100% 自动并排）；图在 `>` 块内时容器每行均带 `>` 前缀。

- **caption → 条目编号解析**（`figure_index.json` 的 `caption` 常带 OCR 噪声）：含 `定理N.S-N`/`引理`/`命题`/`推论`/`例N.S-N`/`定义N.S-N` → 锚定该条目粗体标签；含 `例N`/`例a`（单级）→ 锚定 `**例N**`/`**例a**`；仅含 `图N` 无条目编号 → 按页面位置找到 `## §` 节作"节末尾补充图"，或放弃；完全无法解析 → 放弃嵌入。

- **反例**：把与某例无关的图堆在节末；把独立示意图放无关位置；嵌入后未用 `---` 与下一条目分隔；写成 `](_extract/figure/ch01_...png)`（2026-09-01 起 figure 已在书根，勿加 `_extract/` 前缀）。

- **机器兜底与已知坑**（写源避坑即可，无需手跑）：
  - `flows/script/embed_figures.py`（write-source 步骤 3 强制脚本）会自动：块内缩进（顶层 `<img>` 补 `>`）、连续性修复（块内裸空行转 `> `）、flex 包装；三步幂等。
  - **已知遗留**：顶层图片 `</div>` 后不会自动补空行，会导致 C 层报 "missing blank line after `</div>`"——手动在 `</div>` 与 `---` 间补一个空行即可（块内 `> </div>` 形态无需处理）。

### V-M OCR 漏标条目处理

书中某条重要概念（定义/定理/引理/推论/命题）**确实存在**，但 OCR 未识别其标题（标题行被 DB 检测吞掉、或编号被识别成乱码）→ 总结缺失该条目。标准处理：

- **优先让 OCR 识别出来**：调抽取参数（`--dpi` 200/300/400、`det_db_unclip_ratio` 1.6/1.2/1.0、`det_db_box_thresh` 0.3/0.5）+ 编号归一化（分隔符 ·,．,、→`.`；章首位字母↔数字容错 `A→4`/`O→0` 等）。若整条标题行被 DB 合并吞掉（raw JSON 无该块），参数调优无效，直接进入下一步。
- **凭知识补写并标注（Step 1 失败时）**：agent 依数学知识与上下文补写全文，并在标签追加 `（OCR无法识别）`（英文书同源版同理）；同时在 `_extract/manual_overrides_ch{N}.json` 追加该键（`key`/`page`/`label`/`text`），使抽取器承认其存在、解除 B 层序列缺口 BLOCKING。`manual_overrides` 解 B 层 BLOCKING，`（OCR无法识别）` 向读者声明非 OCR 逐字核验——**两项缺一不可**。
- **over-mark 守卫**：若 `.md` 标了 `（OCR无法识别）` 但该书条目**已被原始 OCR 抽取识别**（非经 `manual_overrides` 恢复）→ verify 报 warning「可能误标，请复核」。经 `manual_overrides` 恢复的条目不误报。
