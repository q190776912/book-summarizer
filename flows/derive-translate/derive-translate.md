# Flow: derive-translate（派生并校验翻译版 / Stage 3）

> 统一模板：目的 / 前置 / 步骤 / 本阶段规则 / 出口 / 相关代码 / 子流程

## 目的
据**已校验的源语言版**派生翻译版（**仅适用于英文书**：英文书 → 中文 `第N章_*.md`），再对翻译版跑批量校验至 PASS。

> 🔴 **适用范围**：本流程只服务**源语言为英文（或其他外语）的书**。**中文书的源语言即中文，无翻译阶段——本章全部步骤整体跳过**，write-source 校验 PASS 即为全书完成（目录契约：`ChapterN_*.md` 英文版仅英文/他语种书时存在；中文书目录下只有 `第N章_*.md` 是合法终态）。
## 前置
- 源语言全部章节已校验通过（`verify PASS + KaTeX OK`），是派生翻译版的**唯一蓝本**。
- 🔴 **修复方向严格单向（最高优先级）**：任何返工 / 修复都先修源语言 → 源语言彻底修复完成（复验 PASS + KaTeX OK）→ 再据已修定源语言同步更新翻译语言。绝不允许翻译语言先于源语言动手，或两边各修各的导致分叉。

## 🔴 翻译硬闸（死规则，不可绕过 / 不可跳步）
> 进入步骤 1（翻译）之前，**必须**确认源语言版已经「写完 + 校验 PASS」全部完成（图片由内容化分章契约的 image 块随草稿继承，最终 md 直接含图，无需单独嵌图步骤）。**缺任一项即立刻 STOP，严禁动手翻译**。此闸由 flow_gate 顺序闸（`write_source` 末步 `verify_source` 未 `done` 则 `derive` 硬拒）与下方自核查命令双重保障。

- **🔴 三项物理证据（缺一即违规）**：
  1. **写完**：源语言 `.md` 已写章数 == `chapter_map` 总章数（顶层 `**定义/定理/例**` 等条目齐备，非空壳）。
  2. **图片**：源版 md 直接含 `![图](…)` 行（图片由内容化分章契约随草稿继承，无需单独嵌图步骤）。
  3. **校验 PASS**：源语言 `verify/script/verify_chapter.py --all <extract_dir> <book_dir>` **真实复验 `exit 0`**（`verify PASS + KaTeX OK`）。
- **🔴 进翻译前的自核查命令（强制，至少跑一次）**：
  ```powershell
  python verify/script/verify_chapter.py --all <extract_dir> <book_dir>   # 仅针对源语言版
  ```
  返回非 `exit 0` → **立即停止**，回到 write-source 修源语言（补写 / `--fix` 复验），**绝不许带着未 PASS 的源语言进入翻译**。
- 🔴 **禁止「源语言写完但未校验就直接翻译」**：这是死规则，违反即全盘返工。源语言必须 `verify PASS` 后才可 `derive`。

## 步骤（有序）
0. **（闸控）先复验源语言**：跑上方自核查命令确认源语言 `exit 0`；非 0 一律回去修源、不翻译。
1. 以已校验源语言版为唯一蓝本，**逐条翻译**出翻译版：条目 / 编号 / 公式 / 图片位置必须 1:1 对应，不得增删或自行发挥；中文版首现术语照旧标 `(English)`。
2. 对翻译版跑批量校验至 PASS：
   ```powershell
   python verify/script/verify_chapter.py --all <extract_dir> <book_dir>   # 针对翻译版
   ```
   未过则 `--fix` 修复 + 重验，至多 2 次仍不过继续修，**严禁停下来问用户**。
   - 🔴 **缺陷溯源判定（翻译版校验失败时的第一步，适用于一切问题，不限格式类）**：中文总结出现**任何问题**（缺条目 / 格式 / 结构 / 公式定界符 / 图等），第一步必须**同步查看源语言版（英文版）对应条目 / 对应区域是否存在同一问题**（grep 对应条目 / 对应区域）。**源版存在同一问题 → 先改好源语言版**（复用 write-source 阶段的修复手段，如 `tools/wrap_examples_bq` / `verify --fix`，修完复验 PASS + KaTeX OK）→ **再据已修定的源语言版同步修改翻译版对应位置**（1:1 对应条目 / 公式 / 图区域，不得只改翻译版造成两版分叉）。源版是因、翻译版是果，绝不允许「跳过查源直接改翻译版」。**仅当核对后确认源版确无此问题时，才允许只修翻译版**（属翻译侧独有缺陷，仍须保持与源版 1:1 同构）。`--fix` 的自动化修复若只动了翻译版，须人工核对源版对应区域并同步。

## 本阶段规则（🔴 内联）
- **规则1 — 源语言优先**：中文版是英文版的**派生**，不是平行独立文件。英文书每章顺序：先写英文源版 → 完全校验 / 修复至 PASS → 再据已校验英文版逐条翻译中文版。
- **🚫 规则2 — 禁止「只有中文、没有英文」（仅英文书）**：英文书的目录下只有 `第N章_*.md` 而无对应 `ChapterN_*.md`，说明流程从根上错，该章（及依赖它的后续章）必须重做。中文总结的存在**以英文源版存在且校验通过为前提**。（中文书不受本条约束——中文书只有 `第N章_*.md` 是正确形态。）
- **规则3 — 中英两版 1:1 同构**：条目、编号、公式、图片位置逐一对应，不得增删或自行发挥。
- **规则4 — 修复严格单向**：先修源语言（英文版）→ 源语言彻底修复完成（复验 PASS + KaTeX OK）→ 再据这份已修定源语言同步更新翻译语言（中文版）。翻译语言总结必须始终以源语言为唯一蓝本、保持一致。
- **🔴 规则5 — 缺陷溯源（一切问题，同 步骤 2）**：中文总结出**任何问题**时，第一步先同步查看源版对应区域是否同样存在该缺陷；存在 → **先修源版再同步翻译版**（两版对应位置必须同时修复）；确认源版没有 → 才可只修翻译版。禁止不查源就动手，禁止两边各修各的造成同构破坏。

## 出口条件（全书完成）
- 出口：**英文书：源语言 + 翻译版章数 == `chapter_map` 总章数，且两版均 `verify PASS + KaTeX OK`；中文书：不进入本流程，write-source 出口即全书出口**。唯一退出条件：`已写章数 == chapter_map 总章数`。
